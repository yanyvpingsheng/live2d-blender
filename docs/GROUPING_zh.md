# 通用分组与训练采样

## 手工映射

侧栏选择 Manual semantic mapping，然后创建模板。模板枚举当前模型的真实 Drawable ID，不猜测身体部件。文本为普通 JSON，例如：

```json
{
  "version": 1,
  "groups": [
    {"name": "my_group_a", "bones": 3, "drawables": ["ExampleDrawableA", "ExampleDrawableB"]},
    {"name": "my_group_b", "bones": 2, "drawables": ["ExampleDrawableC"]}
  ]
}
```

示例 ID 仅为占位；请使用自动模板中的当前模型 ID。骨预算是逻辑影响数，实际 Blender 骨骼数为两倍。每个移动分件必须归属且只能归属一个组；未知 ID、重复归属、组名重复、非法整数预算会报错。完全静止分件可以不分组。每组只有静止顶点时不占用移动预算；其余组预算加上静态影响不能超过侧栏的总预算。

一般每个逻辑影响至少需要三个移动顶点。只有一、两个移动点的组允许一个影响，内部重复约束求解，不新增导出顶点。映射文本不会作为脚本执行；新模板会新建 Text，不覆盖已有编辑。

`DRAWABLE` 模式每个移动分件独立，剩余预算按训练移动量与点数确定性分配。没有面部识别、私有 ID、特定语言名称规则；它不等于编辑器 deformers 或人体关节。细分边界可能妨碍共享运动，负对照曾出现明显退步，因此不是默认。

## bind 和静态点

默认第一帧作为初始 bind。启用修复后只给 XY 数值秩不足、且训练中有更高秩姿态的分件换 bind。这个拼合 bind 可以来自不同时刻，不一定是源模型全局同时出现过的姿态。UV、拓扑、材质、默认图层深度不变。

训练中完全没有展开的部件没有可靠几何信息，保持原状并计入 still_degenerate_pieces。所有训练位置都接近 bind 的顶点使用独立恒等骨影响；容差单位与模型坐标相同。不能由此推断该顶点在另一个动作中仍静止。

## 关键帧和成本

采样步长决定访问源模型的次数。矩阵 subdivisions 只插值已经拟合的端点仿射矩阵，再分解成 Blender 骨关键帧。奇数细分使原区间中点不成为生成关键点，便于独立检验实际 Action 插值。

导出的 FCurve 仍是普通 Blender 关键帧。高密度增加文件大小和依赖图成本，不能替代更多真实训练样本。当前限制训练不超过 1,000 万顶点样本、总逻辑骨 ≤128、细分后关键时刻 ≤20,000、逻辑骨×关键时刻 ≤100,000。上限是防误操作保护，不代表接近上限时性能良好。

报告保留实际骨数、每组预算、静态点数、bind 统计、训练误差和原始/生成关键时刻。未见参数组合、不同动作和像素保真必须额外验证；不会默认称作通过。

## 根对象放置动画

源根对象、父级和约束的 evaluated world transform 额外在每个整数帧及生成骨关键时刻采样，转为独立根对象的普通 location/quaternion/scale Action。因此 Sample step 跳过的整数帧根动作也会保留。根世界矩阵含无法由 TRS 表达的剪切时，转换明确失败并恢复源状态；不把它静默冻结。

这个根轨道同样是采样近似。四元数分量线性插值并连续符号处理，不保证任意子帧与原约束、驱动或 Bezier 完全相等。根轨道最多 20,000 个采样时刻，且不会保留对源父级、约束或驱动器的依赖。
